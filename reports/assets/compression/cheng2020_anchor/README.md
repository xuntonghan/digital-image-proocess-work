# Cheng2020 Anchor Kodak benchmark

These files were produced by `dip-learned-compression-benchmark` with official
CompressAI pretrained MSE models at qualities 1, 3, and 6. Kodak's 24 images
were used only for testing. `compressed_bytes` is the size of the strings
returned by the actual `compress` call; it is not an estimated entropy.

Model weights and all 72 decoded PNG files are intentionally omitted from Git.
