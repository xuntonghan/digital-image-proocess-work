# GeoCorrection 传统几何校正基线

## 结论

200 张图全部成功处理。使用数据集真值页面遮罩的传统方案，把平均页面边界归一化 RMSE 从 0.008357 降至 0.000364，下降 95.64%；文本行平均绝对倾斜角从 8.304° 降至 5.845°，下降 29.61%。200 张中有 169 张的文本行倾斜度改善，19 张由方向检测自动旋转 90°。

这说明单应性和边界展平已经能稳定处理透视、倾斜和页面外轮廓，但仅凭页面轮廓无法完全恢复书脊与页内非线性形变。后者应由 UVDoc、DocScanner 等稠密映射模型解决。

## 实验设置

- 输入：`GeoCorrection/images/` 与同名 `mask/`，共 200 对；
- 遮罩：数据集提供的页面区域真值，属于 oracle 输入；
- 处理分辨率：保持长宽比，最长边 1200；
- 方法：四角单应性 → 上下边界逐列展平 → 左右边界逐行展平 → 文本方向自动校正；
- 环境：本机 CPU，NumPy、Pillow、scikit-image；
- 输出：200 张校正图、200 张校正遮罩、逐图 CSV、汇总 JSON 和代表图。

运行命令：

```bash
dip-rectify-classical \
  --data-root data/geocorrection/GeoCorrection \
  --output-dir outputs/geocorrection/classical_full \
  --max-side 1200 --expected-count 200
```

## 全量指标

| 指标 | 输入 | 单应性后 | 最终校正 | 说明 |
|---|---:|---:|---:|---|
| 页面边界 RMSE（归一化，低优） | 0.008357 | 0.005009 | **0.000364** | 四条边到对应直线的误差 |
| 页面边界 P95（归一化，低优） | 0.020424 | 0.012900 | **0.000231** | 抑制少量离群点后的边界诊断 |
| 页面填充率 | 0.4126 | 0.9866 | **0.9998** | 校正遮罩占输出矩形比例 |
| 文本行倾斜角（°，低优） | 8.304 | 6.195 | **5.845** | 文本边缘 Hough 主方向绝对偏差 |
| 单张处理时间（ms） | — | — | 719.6 | 本机 CPU，含几何处理，不含磁盘写入 |

页面填充率接近 1 只代表输出边界矩形化，不代表页内文字已经完全去弯曲；因此必须与文本行和 OCR 指标结合解释。

## 指标口径与限制

数据没有与输入逐像素对应的平整真值，因此本阶段不报告 PSNR/SSIM。直接拿输入和校正结果计算它们没有物理意义，因为正确的坐标重映射本身就会改变像素位置。

文本行倾斜度是无需真值的诊断指标，不是 OCR 准确率。漫画、图表、竖排文本和多方向布局会降低 Hough 指标的可信度；这也是少数视觉正确样本的数值仍可能退化的原因。OCR 评价将在同一固定测试集上使用 PaddleOCR 补齐。

当前方法还依赖真值遮罩，不能代表真实端到端部署。下一阶段需要训练/接入自动页面分割，再在 4090 上比较 UVDoc 等稠密展平模型。
