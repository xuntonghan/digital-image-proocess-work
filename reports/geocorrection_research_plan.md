# 几何校正任务理解与研究路线

## 1. 课件要求与交付物

课件第二部分要求自建 200 张文档图像，覆盖透视变形、页面弯曲和倾斜等情形，将输入恢复为平整、规则、便于阅读和后续识别的页面。验收至少包括：

1. 数据读取与检查；
2. 算法设计及实现；
3. 校正前后可视化对比；
4. 文本行规整度评价；
5. OCR 识别效果评价；
6. 可复现源码、部署说明和实验报告。

本仓库先建立可解释、可复现的传统基线，再接入预训练深度模型，最后依据 OCR 与视觉结果决定是否微调。

## 2. GeoCorrection 数据审计

`GeoCorrection.zip` 共包含 200 张 RGB JPG 和 200 张同名灰度 PNG 遮罩，图像与遮罩严格一一对应、尺寸一致。完整 SHA256 和逐文件信息见 `manifests/geocorrection/`。

| 项目 | 结果 |
|---|---:|
| 图像/遮罩对 | 200 |
| 图像模式 | RGB |
| 遮罩模式 | L，且像素严格为 0/255 |
| 分辨率种类 | 6 |
| 分辨率分布 | 3000×4000（16）、3120×3120（2）、4000×3000（66）、4208×3120（19）、4624×3472（50）、5248×3936（47） |
| 平整真值图 | 无 |
| 稠密反向映射真值 | 无 |

文件名可分为普通拍摄、时间戳拍摄、书页、曲面、折叠、透视和旋转七类。遮罩只描述畸变图像中的页面区域，并不是展平后的答案图。这带来三点约束：

- 可以利用现有遮罩做传统轮廓/边界引导校正，也可训练页面分割器；
- 不能只用这 200 对数据监督训练稠密展平网络，因为没有目标平整图或映射场；
- 不能把输入图与校正结果直接计算 PSNR/SSIM，那会错误地惩罚必要的几何变化。

## 3. 已完成的传统算法设计

当前基线的处理顺序是：

1. 将原图和二值遮罩等比例缩放到最长边 1200，降低本机实验成本；
2. 从遮罩轮廓四个方向的极值估计左上、右上、右下、左下四角；
3. 求解单应性，将页面投影到规则矩形；
4. 逐列估计上下边界、逐行估计左右边界，利用分段反向映射消除单应性后残留的外轮廓弯曲；
5. 用文本边缘的 Hough 方向票数自动判断横竖版，对竖倒页面旋转 90°；
6. 输出校正图、校正遮罩、逐图指标、分组汇总和四列对比图。

这个算法使用数据集提供的真值页面遮罩，因此属于 **oracle-mask classical baseline**，不是最终的端到端自动系统。它的价值是提供一个无需训练、行为可解释且可供后续模型比较的下限/诊断基线。

## 4. 论文与代码路线比较

优先选择有正式论文、作者代码和可取得权重的方案。

| 方法 | 发表 | 核心思路 | 本项目用途 | 注意事项 |
|---|---|---|---|---|
| [DewarpNet](https://github.com/cvlab-stonybrook/DewarpNet) | ICCV 2019 | 堆叠 3D 形状与 2D 展平回归 | 经典学习基线、理解形状先验 | 较老，部署链路重 |
| [DocTr](https://github.com/fh2019ustc/DocTr) | ACM MM 2021 | Transformer 预测像素级位移 | 稠密映射对照 | 需要作者权重与环境适配 |
| [DocGeoNet](https://github.com/fh2019ustc/DocGeoNet) | ECCV 2022 | 显式 3D 形状与文本行几何 | 强曲面书页对照 | 训练依赖合成数据 |
| [UVDoc](https://github.com/tanguymagne/UVDoc) | SIGGRAPH Asia 2023 | 联合预测 3D 网格与 2D 反向映射 | **首选预训练几何模型** | 原始仓库 MIT；先零样本测试 |
| [DocRes](https://github.com/ZZZHANG-jx/DocRes) | CVPR 2024 | 统一去弯曲、去阴影、去模糊等恢复任务 | 几何后处理/外观恢复对照 | 不应与纯几何增益混报 |
| [DocScanner](https://github.com/fh2019ustc/DocScanner) | IJCV 2025 | 渐进循环校正 | 复杂弯曲强基线 | 仓库许可限制非商业使用 |
| [DocMatcher](https://github.com/FelixHertlein/doc-matcher) | WACV 2025 | 文本与结构线匹配 | 有平整模板时的可选上限 | 当前数据没有模板 |
| [ForCenNet](https://github.com/caipeng328/ForCenNet) | ICCV 2025 | 前景中心、遮罩引导和曲率一致性 | 与现有页面遮罩最契合的研究方向 | 先核实权重与复现条件 |
| [D2Dewarp](https://github.com/xiaomore/D2Dewarp) | CVPR 2026 | 水平/垂直双维线几何表示 | 最新文本行几何对照 | 代码已公开，权重可用性需复核 |

Hugging Face 上已有 [PaddlePaddle/UVDoc](https://huggingface.co/PaddlePaddle/UVDoc) 和 Transformers 的 [UVDoc 文档](https://huggingface.co/docs/transformers/en/model_doc/uvdoc)，适合统一成可复现推理入口。社区还有 [UVDoc ONNX 网格模型](https://huggingface.co/fredcallagan/uvdoc-grid-onnx)，可用于验证“低分辨率预测网格、高分辨率原图重映射”，但它不是作者官方发布，实验中必须单独标注来源。

## 5. 推荐实施顺序

### 阶段 A：传统 oracle-mask 基线（已完成）

- 完成 200 对数据审计；
- 完成单应性、边界展平、自动方向校正；
- 输出全量结果与无需真值的边界/文本行诊断指标；
- 人工检查各类代表图与指标退化样本。

### 阶段 B：自动页面区域定位

将数据按文件族分层固定划分为训练/验证/测试集，训练轻量页面分割器，替换推理时的真值遮罩。该阶段只使用现有遮罩监督，报告 IoU、Dice 以及遮罩误差对最终几何结果的影响。

### 阶段 C：4090 上的预训练稠密展平

首选 UVDoc 做零样本推理，再以 DocScanner 或 DocGeoNet 做强基线。统一保存低分辨率位移/网格，尽可能在原分辨率图像上执行最终重映射。比较：

- 传统 oracle mask；
- 自动分割 + 传统校正；
- UVDoc；
- UVDoc + 外观恢复（可选 DocRes）。

### 阶段 D：OCR 与文本行评价

在固定测试集上使用同一版本、同一参数的 PaddleOCR，分别评价输入和各方法输出。至少记录可识别文本数、平均置信度；若人工转录一小部分页面，再增加字符错误率 CER。没有人工转录时，不把 OCR 置信度包装成识别准确率。

### 阶段 E：针对性提高

根据失败类型决定是否训练：

- 主要失败是页面没找准：增强页面分割；
- 主要失败是书脊/曲面：使用 Doc3D、UVDoc 等带稠密真值的合成数据微调；
- 主要失败是阴影/模糊：把几何与 DocRes 外观恢复分成两个消融步骤；
- 主要失败是漫画、表格等混合版面：按版面类别报告文本行指标，避免单一 Hough 均值误导。

## 6. 评价原则

- **有平整真值时**：MS-SSIM、局部畸变/对齐距离、OCR CER；
- **当前无平整真值时**：页面边界直线度、文本行倾斜度、OCR 置信度/数量和盲测可视化；
- **分割阶段**：IoU、Dice；
- **效率**：预处理、模型推理和原分辨率重映射分别计时；
- 每个模型固定版本、权重哈希、数据划分和随机种子，测试集只在方案冻结后统一评价。

当前传统结果见 `reports/geocorrection_classical_baseline.md`。下一步需要 4090 云机完成阶段 C 与 D。
